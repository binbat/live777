# Microsoft Visual C++ runtime notice

Windows diagnostics bundles include unmodified Microsoft Visual C++ runtime
DLLs (`vcruntime140*`, `msvcp140*`, `concrt140*` and, when present,
`vccorlib140*`). These are Microsoft proprietary redistributables, not
open-source vcpkg libraries, and no Microsoft source code is included in the
source archive.

Microsoft's redistribution terms and the matching official redistributable are
available at https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist .

https://visualstudio.microsoft.com/license-terms/ .
